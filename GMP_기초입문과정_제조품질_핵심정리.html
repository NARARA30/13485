전체 커리큘럼 · 큰 그림

의약품 제조·품질 입문자를 위한 기초 과정이다. 산업 이해 → GMP 개념 → 품질보증 시스템(문서·일탈·변경·CAPA·데이터) → 밸리데이션(검증) → 실습/취업 준비의 흐름으로 구성된다.

1차시제약산업·공장 부서(QA/QC/제조) 이해
2차시GMP 정의·역사·10대 원칙·약사법
3차시품질보증(1): 문서·일탈·OOS·자율점검·공급업체
4차시품질보증(2): 변경·CAPA·DI·포장·무균·불만
5차시밸리데이션: 공정·적격성·세척·CSV·맵핑
6차시불만 보고서 실습 + 취업 Q&A
QA vs QC 한 줄: QA=품질보증 시스템 총괄(문서·일탈·변경·출하승인), QC=품질관리 시험 수행(이화학·미생물·안정성).

1차시 · 제약 산업의 이해

제약산업과 신약 개발

  • 제약산업: 의약품을 연구개발·제조·가공·보관·유통하는 산업. 의약품=대한민국 약전에 실린 물품 중 의약외품이 아닌 것.
  • 신약 개발 과정: 후보물질 탐색 → 임상(전임상~임상3상, 최소 200억~최대 1조, 3~10년) → 신약허가 신청·승인(0.5~2년) → 시판(상업화).

기업특징

한미약품 / 대웅제약한미: 랩스커버리 플랫폼 / 대웅: 보툴리눔 톡신(나보타).

필요 역량: 의사소통(유관부서 협의), Trouble Shooting 아이디어, 데이터 분석·경향분석, 공정·프로세스 개선(인적오류 최소화).

2차시 · GMP 소개

GMP 정의와 핵심 목표

GMP는 소비자 안전을 최우선으로 품질·신뢰성을 보장하는 글로벌 품질관리 시스템. 핵심 목표: 소비자 안전 보장 · 품질 일관성 유지 · 오류/혼입/교차오염 방지 · 법적 요구사항 준수 · 글로벌 경쟁력.

GMP의 역사 (빈출)

연도사건 / 의의
1937설폰아마이드(엘릭서) 사건 — 디에틸렌글리콜 용매, 독성검사 없이 판매, 약 100명(대부분 어린이) 사망 → 1938 미국 FD&C법 제정(의약품 안전성 검토 의무화).
1960s탈리도마이드 사건 — 임산부 진정제, 태반 통과로 약 1만명 기형아 → 국제 의약품 안전규제 강화, FDA 허가 시스템 기초.
1963미국 FDA GMP 제정.
1975WHO 국제 GMP 가이드라인 발표.
1980s국내 KGMP 도입.
2014한국 식약처 PIC/S 가입(국제 GMP 상호 승인).
현재디지털 GMP — Data Integrity, QbD, 전자기록(EDMS·MES·QMS·LIMS).

GMP 10대 원칙

  • 위생 관리 · 문서화(기록하지 않은 작업은 하지 않은 것) · 교육과 훈련 · Validation(공정·설비·세척·환경 검증) · 설비/환경 관리(모니터링·경향분석)
  • 원자재 관리(과학적 샘플링·공급업체 평가) · 변경관리 · 오염 방지(CCS, 청정도) · 품질관리(로트별 기준 충족) · CAPA(원인분석·재발방지)

약사법 내 GMP 관련 조항

조항내용
제31조의약품 제조업 허가 — 시설·설비·품질관리가 GMP 적합해야 허가.
제45조제조 및 품질관리기준(GMP) 준수 — 위반 시 제조정지·허가취소.
제47조제조관리자·품질관리자 선임(공정 감독 / 품질 감독·출하승인).
제85조행정 처분 — 제조정지·회수명령·허가취소·과태료.
사후관리: 국내 제조·수입 의약품 모두 GMP 적용, 식약처가 3년마다 인증 심사(갱신).

3차시 · 품질보증 시스템의 이해 (1)

품질보증 시스템 구성: 문서화&Compliance(문서·변경·일탈·OOS·불만), 제조 시스템(공정·세척·밸리데이션), 시설·설비(교정·유지보수), 원자재(공급업체 평가), 시험실(안정성·적격성·시험법 밸리데이션), 자율점검·연간제품품질평가.

① 문서 관리 (근거: 안전규칙 별표1 제5항)

  • 모든 기록문서는 작업과 동시에, 지울 수 없는 잉크로 작성. 수정 시 선 긋고 수정사유·연월일·서명.
  • 보존: 기록문서(전자기록 포함)는 유효기한/사용기한 경과 후 1년간 보존.
  • 문서 유형: SOP(표준작업절차) · 제조기록서(Batch Record) · 로그북(장비·시설 사용내역) · 변경관리 문서 · 기준서(제조관리/품질관리/제조위생관리 기준서, 제품표준서).

② 일탈 관리 (Deviation)

일탈=사전 승인된 절차에서 벗어난 모든 사건. 절차: 일탈 보고 → 원인 조사 → CAPA(시정·예방조치).

  • 대상: 공정조건·수율·공정검사(IPC)·품질시험·원자재·작업장 환경(온습도·차압)·설비·제조용수·출하·밸리데이션·전산시스템.
  • 사례: 원료 투입량 오류(→저울 교정·재교육), 청소 미흡(→체크리스트·재교육), 온습도 일탈(→모니터링 빈도·알람).

③ 기준 일탈 관리 (OOS, Out of Specification)

  • OOS=시험 결과가 사전 설정 규격을 벗어난 경우. Phase 1(시험실 오류 조사: 장비·환경·기록) → Phase 2(제조공정 조사: 원료·환경·작업자) → CAPA.
  • 적용: 원료입고·완제품 출하적부·안정성 시험. 예외(일탈 절차로): 공정검사·환경모니터링, 밸리데이션·개발/임상용 시험.
일탈 vs 기준일탈: 일탈(Deviation)=절차 이탈(공정·환경 등), 기준일탈(OOS)=시험 결과가 규격 이탈. OOS는 Phase 1(시험실)→Phase 2(제조) 조사가 특징.

④ 자율점검 (Self-Inspection)

  • 회사 내부 QA가 GMP 준수를 정기적으로 점검(연간계획). 결과·개선요구사항 보고서 작성, 기한 정해 개선.
  • vs 외부감사: 자율점검=내부 QA·연간계획·사전예방 / 외부감사=규제기관·관계사·규제요구 준수 확인.

⑤ 공급업체 평가 (Vendor Audit)

  • 선정기준: GMP 인증 여부, 품질시스템, 과거 감사이력·CAPA, 원자재 품질, 재무건전성.
  • 절차: 선정 → 문서 평가 → 현장 감사 → 평가보고서 → 정기 평가.

4차시 · 품질보증 시스템의 이해 (2)

① 변경 관리 (Change Control · 근거: 별표1 제12항)

  • 기계설비·원자재·제조공정·시험방법 변경 시 품질·재현성 영향 검토 → 문서화, 필요 시 밸리데이션·안정성 시험·공급업체 평가.
  • 절차: 변경요청 → 변경평가(영향·규제 충족) → 승인(QA) → 실행 → 검토·종료. 실행 시 문서 개정·작업자 교육 수반.

② CAPA (시정 및 예방조치)

  • 시정조치(Corrective)=이미 발생한 문제의 근본원인 제거 / 예방조치(Preventive)=재발 방지 사전 조치.
  • 절차: 문제 식별 → 원인 분석 → 시정·예방조치 수립 → 실행·기록 → 유효성 확인 후 종료(재발 여부·의도한 결과 확인).

③ 데이터 완전성 (Data Integrity) — ALCOA+

원칙의미
Attributable(기인성)작성·수정·확인자가 명확히 식별.
Legible(가독성)읽기 쉽고 명확.
Contemporaneous(동시성)생성 시점과 동일하게 기록.
Original(원본성)원본 보존, 복사본은 원본과 일치.
Accurate(정확성)사실 기반, 오류 없음.
+ Complete·Consistent·Enduring·Available완전·일관·영구·활용(필요 시 접근 가능).
보장 방법: 사용자 권한 관리, 전자서명, Audit Trail(변경내역 자동기록), 정기 백업·복구 테스트. 국제근거: FDA 21 CFR Part 11, EU GMP Annex 11.

④ 포장자재 관리

  • 1차 포장자재=의약품과 직접 접촉(보호·오염방지) / 2차 포장자재=1차 보호·정보 제공.
  • 절차: 구매(승인업체) → 수령·검수(시험) → 보관(상태 구분) → 사용(적합만) → 폐기(문서화). 표시기재 오류 시 출하금지·회수·식약처 보고.

⑤ 무균 공정 관리

  • 무균제제: 앰플·바이알·프리필드시린지·BFS. 관리: 장비 멸균, 작업자 관리, 환경 모니터링(입자·미생물), 무균공정 검증.
  • Media Fill Validation(무균충전 검증): 배지(TSB)를 실제 충전 조건으로 충전 → 약 14일 배양 → 미생물 미검출 시 검증.

⑥ 소비자불만 관리 (근거: 별표1 제11항)

  • 불만처리규정·불만처리위원회 운영. 절차: 접수·기록 → 근본원인 조사 → CAPA → 결과 보고·종료.
  • 기록 필수: 제품명·제조번호, 제기자 정보, 접수일, 불만내용, 처리결과·조치.

5차시 · 밸리데이션의 이해

밸리데이션=공정·절차·설비·시스템·분석법이 사전 설정 기준을 지속적으로 충족함을 과학적·체계적으로 증명·문서화하는 활동. 범위: 공정 밸리데이션 · 적격성평가 · 세척 밸리데이션 · CSV · 온습도맵핑.

대상(별표1 제6.1): ①새 품목 최초 제조 ②품질 영향 기계·설비 설치 ③품질 영향 제조공정 변경 ④제조환경 변경 → 계획서에 따라 실시.

① 공정 밸리데이션 (Process Validation)

  • 필수요소: CQA(중요 품질 속성: 용출·균일성·순도) / CPP(중요 공정 변수: 온도·압력·혼합속도).
  • 종류: 예측적(판매 전, 원칙) / 동시적(부득이한 경우 제조·판매하며) / 재밸리데이션(정기 또는 중대 변경 시). 예측·동시 모두 실생산 연속 3개 제조단위 실시, 3개 모두 적합해야 함.

② 적격성평가 (Qualification) — DQ·IQ·OQ·PQ

단계확인 내용
DQ 설계적격성설계가 사용자 요구·규제 요건 충족(사양서·도면).
IQ 설치적격성설계대로 설치(설치상태·매뉴얼·교정인증서·전원/배관).
OQ 운전적격성규정 조건에서 의도대로 작동(기능·최소/최대 조건·알람).
PQ 성능적격성실제 운영 환경에서 일관 작동·품질기준 충족(반복성).
필수 문서: VMP(Validation Master Plan), DQ/IQ/OQ/PQ 보고서. 고위험 장비·공정 우선.

③ 세척 밸리데이션 (Cleaning Validation)

  • 목적: 교차오염 방지·잔류물 기준 이하 검증. 검증범위: 주성분(API)·세척제·미생물.
  • MACO(Maximum Allowable Carryover) 허용 잔류량 설정. 샘플링: Swab(표면 직접) / Rinse(헹굼). 분석: HPLC·TOC·UV·미생물. 최악 조건(Worst Case)에서 실시.

④ 컴퓨터 시스템 밸리데이션 (CSV)

  • 대상: MES·QMS·LIMS·EDMS·WMS. 단계: 계획(VMP·위험평가) → DQ → IQ → OQ → PQ.
  • 구성요소: ALCOA+ 데이터 완전성, 전자서명·Audit Trail, 권한 관리, 위험평가, 백업·복구, 보안.

⑤ 온습도 맵핑 (Temperature/Humidity Mapping)

  • 목적: 보관·운송 환경의 온습도가 규정 범위 유지 확인, Hot/Cold point 식별. 대상: 보관소, 냉장(2~8℃)·냉동(-20℃↓), 운송차량.
  • 단계: 계획(허용범위) → 센서 배치(3D 그리드) → 데이터 수집(로거, 1~5분 간격) → 분석(최고/최저/평균·편차·Hot/Cold point). 센서 정기 교정 필수.

6차시 · 소비자불만 보고서 실습 + 취업 Q&A

소비자불만 조사 보고서 구조

  • 1. 개요: 불만내용·제품명/제조번호·불만제기처·접수일(현물 접수일).
  • 2. 근본원인 조사: 현물 확인 → 제조공정 중 발생 가능성 → 보관/유통 중 가능성 → 재현성 테스트로 원인 규명(예: 낙하 충격 시 정제 파손 재현).
  • 3. CAPA: 시정조치(회수·교품) + 예방조치('취급주의' 표시, 완충 포장 절차·교육, 배송 외관점검 추가).

취업·실무 Q&A 핵심

필요 경험실험실 실습(HPLC·GC), GMP 기본지식, 인턴십.

파이널 프로젝트 (초급 · 중급)

초급 — 기준일탈(OOS) 대응 실습

  • 상황: 완제품 출하적부 함량시험 OOS(기준 95.0~105.0% → 측정 107.2%), 이전 3개 로트는 적합.
  • 과제: 즉시 조치 3가지(우선순위) → Phase 1(시험실 오류 조사) → Phase 2(제조공정 조사) → CAPA. 관련 법적 근거(안전규칙) 인용.

중급 — 무균 바이알 충진 통합 품질관리 계획

  • 주제: 무균 주사제(바이알) 충진 공정의 전 영역 통합 품질관리 계획서 작성(일 10,000 바이알, 국내 GMP+ICH).
  • 과제: 공정 흐름도(바이알 준비→충진→마개→크림핑→검사)·관리포인트, CQA(무균성·충진량·입자) 허용기준, 위험기반 접근(Risk-based) 적용.
작성 원칙: QA 담당자 관점 + GMP 규정·법적 근거 + 현장 적용 가능한 구체적 방안 + 단계별 절차·근거.

시험 · 실무 포인트 요약

  • GMP 역사 4대 사건: 설폰아마이드(1937)·탈리도마이드(1960s)·FDA GMP(1963)·WHO(1975), KGMP(1980s), PIC/S 가입(2014).
  • QA vs QC: QA=시스템 총괄·출하승인, QC=시험 수행.
  • 일탈 vs 기준일탈(OOS): 절차 이탈 ↔ 시험결과 규격 이탈(Phase 1 시험실 → Phase 2 제조).
  • CAPA: 시정(근본원인 제거) + 예방(재발 방지), 유효성 확인 후 종료.
  • ALCOA+: Attributable·Legible·Contemporaneous·Original·Accurate + Complete·Consistent·Enduring·Available.
  • 밸리데이션 4종 + 맵핑: 공정(예측·동시·재, 연속 3배치)·적격성(DQ·IQ·OQ·PQ)·세척(MACO·Swab/Rinse·Worst Case)·CSV(MES·LIMS…)·온습도맵핑(Hot/Cold point).
  • 무균: Media Fill(TSB, 14일 배양). 약사법 GMP 조항: 31·45·47·85조. 인증 갱신 3년.
